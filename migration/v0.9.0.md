# Migrating to v0.9.0

v0.9.0 returns a typed `*APIError` for every non-2xx response from the
Proxmox API, so callers can classify errors with `errors.Is` / `errors.As`
instead of matching on `err.Error()`.

## TL;DR

No signatures changed. Four behaviours did:

| Change | Affected callers | Fix |
|---|---|---|
| Non-2xx statuses other than 400/401/403/500/501 (`404`, `502`, `595`, `596`, ...) now return an error. They used to fall through to JSON decoding and usually returned `nil`. | Code that relied on a 404 or proxy error being silently ignored | Check `proxmox.IsNotFound(err)` (or the other helpers) where a missing resource is expected |
| 401/403 return an `*APIError` instead of the bare `ErrNotAuthorized` value | `err == proxmox.ErrNotAuthorized` | `errors.Is(err, proxmox.ErrNotAuthorized)` or `proxmox.IsNotAuthorized(err)` |
| A 400 with a non-JSON body returns an `*APIError` instead of a JSON decoding error | Anyone matching on `invalid character ...` | `proxmox.IsBadRequest(err)` |
| The `Error()` text of a 500/501 may gain a `: <detail>` suffix when PVE's message spans more lines than the status line holds | Exact-equality comparisons on `err.Error()` | Use `strings.HasPrefix` / `strings.Contains`, or better, the helpers below |

## Classifying errors

```go
// before
if err != nil && strings.Contains(err.Error(), "does not exist") {
    // create it
}

// after
if proxmox.IsNotFound(err) {
    // create it
}
```

| Sentinel | Helper | Matches |
|---|---|---|
| `ErrNotFound` | `IsNotFound` | `404`, and PVE `500`/`400` messages saying a resource doesn't exist |
| `ErrNotAuthorized` | `IsNotAuthorized` | `401` and `403` (unchanged) |
| `ErrForbidden` (new) | `IsForbidden` | `403` |
| `ErrBadRequest` (new) | `IsBadRequest` | `400` |
| `ErrRateLimited` (new) | `IsRateLimited` | `429` |
| `ErrNodeUnreachable` (new) | `IsNodeUnreachable` | `595` / `596` |

For the details, use `errors.As` or the `AsAPIError` shortcut:

```go
if apiErr, ok := proxmox.AsAPIError(err); ok {
    fmt.Println(apiErr.StatusCode, apiErr.Message)
    for param, msg := range apiErr.Errors {
        fmt.Printf("  %s: %s\n", param, msg)
    }
}
```

## What `Error()` still prints

The text is kept so existing string matches keep working:

| Status | Before | After |
|---|---|---|
| 500 / 501 | `500 Configuration file '...' does not exist` | unchanged; a `: <rest of message>` suffix is added only when PVE's message has more than the status line shows |
| 400 | `bad request: 400 Parameter verification failed. - {"vmid":"..."}` | unchanged |
| 401 / 403 | `not authorized to access endpoint` | `not authorized to access endpoint: 403 Permission check failed (/vms/100, VM.Audit)` |
| other | usually no error | `404 Not Found`, `595 Connection refused`, ... |

## Retries

`WithRetry` is unchanged and still decides on the raw HTTP status at the
transport layer. When the retries run out, the last response becomes an
`*APIError`, so `apiErr.StatusCode` is the status of the final attempt.
